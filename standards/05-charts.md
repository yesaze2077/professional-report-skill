# 05｜图表与证据表达

## 先决定要证明什么，再选择图型

先写读者问题，再列可用数据，再决定是否需要图。一句话更清楚时不画图；需查精确值时优先表格。图的复杂程度不代表报告深度。

每张图具备：图号、图题、对象／期间／单位／分母、主体图形、必要标注、来源与限制、邻近解释。图题与分析结论可以相邻但不机械重复。

## 视觉证据选择

图表用于关系、变化和分布；截图用于证明具体界面、状态或文案；流程图用于步骤、角色、依赖和判断分支；重点框用于本页最重要的结论、风险或待决事项。它们各有职责，不为填满版面而添加。每页选择一个主证据载体；必要时两种互补并置，且正文解释它们如何共同支持判断。图片和图表应有图号、可访问替代文字、来源／制作方式、时间或版本及必要限制。

截图先核对使用权和隐私，再裁剪到与论点相关的区域；遮盖个人信息、账号、令牌及内网地址。裁剪、模糊、拼接、箭头或高亮均须保持原语境，不得让旧界面看似现状，不能用合成界面冒充真实证据。真实截图应注明采集日期和对象；模拟界面显著标“合成示意”，不得承担真实业务事实。

流程图明确起止、步骤、决策条件、角色与方向；数据量或转化率写在相应节点并给分母、期间和来源。没有真实测量的阶段只展示流程，不填假比例。流程图无法清晰解释时改用步骤表或短段落。

重点框限于能改变阅读路径的信息，优先突出结论与含义，不重复全文。风险框区分已观察问题和待验证可能性；颜色和图标不能单独承载状态。图表、截图与文字保持一致的编号、间距、标注和视觉层级。

## 常用图型与门槛

| 目的 | 首选形式 | 不应忽略 |
|---|---|---|
| 看变化趋势 | 折线图 | 连续且可比的观测；缺失断线；估算与实际区分 |
| 看排名或长中文类目 | 横向条形图 | 零基线；排序与对象固定；不要截断类目含义 |
| 看前后差异 | 哑铃图或分组条形图 | 相同尺度；标明两个时期；差值标签 |
| 看总体如何变化 | 瀑布图 | 期初＋各项变化＝期末；负贡献；方法说明 |
| 看构成 | 堆叠条形图 | 类别互斥、总量完整；比较占比时同时提示总量 |
| 看波动和分布 | 直方图／箱线图 | 分箱或分位定义；样本量；别只报均值 |
| 看关系 | 散点图 | 单位、样本、异常点；相关不等于因果 |
| 看留存 | 队列热力图 | 同批定义、基数、观察窗；未成熟不为0 |
| 看流程 | 阶段转化表／漏斗 | 同一对象、窗口、去重和顺序；分步率与累计率分开 |
| 看不确定性 | 区间图／区间表 | 区间类型、计算依据；情景区间不叫置信区间 |
| 看精确记录 | 表格 | 数字右对齐，单位进表头；保留总计及注释 |
| 看执行顺序 | 里程碑／行动表 | 依赖与负责人状态；建议安排不冒充承诺 |

`catalog/charts.json` 提供具体选择、禁用条件、必需标注与实现状态。

## 坐标轴与编码

条形图与面积编码原则上从0开始，负值向相反方向延伸。折线和点图可使用非零轴，但刻度清楚、选择有解释，不制造夸张差异。对照图用同尺度；确有需要不同尺度时显著注明。

禁用3D柱体、透视饼图、以图标面积冒充长度、倒置无说明坐标、故意不等间距时间轴。双轴默认不用；不同量纲优先分图或使用明确基期的指数图。指数图说明“某期=100”，不能混淆绝对规模。

泡泡图按面积而非半径映射数值。地图只在空间关系有意义时使用，销量大的地区不一定转化效率高。桑基图仅在节点流量可核对时使用，不能把非互斥归因收入画成守恒流。

## 标注和视觉焦点

一张图集中说明一个主要关系。强调关键序列或异常，其余降低视觉权重，但不得隐藏反证。折线通常控制在3—4条；更多序列可拆图，不为此丢掉必要人群。

长中文标签优先横向展示或自然换行，不把所有字旋转90度。关键数据尽量直接标注，减少读者在图例与图形之间往返。图下解释必须说明含义，不只是逐个朗读数据。

## 颜色

默认中性色＋一个强调色，状态需要额外区分时再增加。全文同一对象使用一致语义。增长不自动为绿色，下降不自动为红色；成本下降和收入下降的业务含义不同。中国资本市场红涨绿跌与经营报表正负状态不同，不能混用。

除颜色外保留文字、正负号、线型或标记。打印为灰度仍应能区分。缺失与零值采用不同文字或底纹，不能仅靠颜色深浅。

## 图表来源与解释示例

“图1｜渠道净销售额变化；2026年第二季度较第一季度；单位：万美元。”

“付费渠道记录的净增量为18万美元，占全站24万美元净增量的75.0%。该比例按互斥的单一归因口径计算，说明收入记录集中度；不等同于广告的因果增量。”

“资料来源：合成示例S1，按渠道汇总；统计不含税费和运费，退款按指定截止日扣除。”

## 不确定性与精度

实际、估算、目标、预测分别标注。未来区间没有建模依据不能随意画阴影带。图形保留与数据支持相符的精度；字号不够时减少标签或拆图，不缩小到无法阅读。
