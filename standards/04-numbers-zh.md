# 04｜中文数字与数据呈现

## 一条数字的完整语境

关键数字在其所在分析单元内应能找到：**是什么、针对谁、哪个期间、什么单位、和谁比较、用什么口径、来自哪里**。信息可以分配在正文、图题、表头与脚注，不必每个数字后重复七遍。

底层存数值，展示层负责中文单位与舍入。不得把“1.2万”作为原始计算值，也不得先舍入再计算百分比。

## 数字呈现速查

| 情境 | 推荐显示 | 注意 |
|---|---|---|
| 管理摘要的大金额 | 144万美元、1.25亿元 | 不默认写$1.44M；保留币种 |
| 同一图的金额 | 图题写“单位：万美元”，标签120、144 | 同图不混120万与0.0144亿 |
| 小额单价 | 59.90美元 | 按价格业务所需精度 |
| 重要整数 | 1,142人／4,021份 | 查数时保留千位分隔 |
| 估计规模 | 约120万—150万美元 | 不给无法支持的个位精度 |
| 普通占比 | 32.5% | 正文通常1位小数 |
| 转化率 | 3.00%→2.40% | 根据差异大小保留必要精度 |
| 率的变化 | 下降0.60个百分点 | 不写“下降0.60%” |
| 相对变化 | 下降20.0% | 分母为正且可比的基期 |
| 目标完成率 | 96.0%，较目标少6万美元 | 区分金额缺口与率差 |
| 样本内主题 | 65／200份，32.5% | 不自动写成“32.5%的客户” |
| 无法计算 | 不适用／基期为0 | 不显示∞%或0% |

以上小数位是本包默认值，涉及微小但重要差异时增加精度；涉及估计不确定性时减少精度。不能为了统一到1位小数，把真实的0.04个百分点抹成0.0。

## 关键数值与比例双显

在分母清晰、口径一致且有助于读者判断规模时，**百分比同时给具体分子／分母或等价基数**。例如“转化率2.88%（7,200／250,000次会话）”“样本内提及率32.5%（65／200份有效反馈）”。图内拥挤时可在图题或表头统一注明共同分母，并在关键标注保留数量。加权比例不得反推伪造人数，需分别列加权比例和未加权样本量。

重要绝对值在解释结构、集中度或影响范围时，**同时给与同口径总体的占比**。例如“付费渠道净销售额54万美元，占同口径净销售额144万美元的37.5%”；非互斥渠道、平台归因与店铺收入不得拼成共同总体。绝对值本身已足够或分母不稳定时无需凑占比。

比较可比期间时优先同时给**基期值、本期值、绝对变化、相对变化**。例如“净销售额由120万美元增至144万美元，增加24万美元，增幅20.0%”；率值应分别注明“由3.40%降至2.88%，下降0.52个百分点，相对降幅15.3%”。相对变化的分母是基期，百分点是两率直接相减，二者不可互换。

这不是机械补齐规则：分母不存在或不稳定、样本不完整、期间或归因不可比、基期为0或极小、隐私抑制导致基数不可披露时，标注原因并保留可核实的绝对值或范围；不得推导看似精确的比例。双显后的数字也需核对计算、单位、舍入与来源。

## 百分比、百分点与倍数

从20%到25%：上升5个百分点，相对增长25%。从100到200：增至2倍，增长100%；“增长2倍”容易被理解为增至3倍，避免使用。

当底层率用0—1存储时：

- 显示百分比＝率×100；
- 百分点变化＝（本期率－基期率）×100；
- 相对变化＝（本期值÷基期值－1）×100%，要求基期正且口径可比。

不得把2.4作为比例原值后再次乘100。接口使用0—100时先记录并转换到统一量纲。

## 同比、环比与截至日期

正文写清“同比”或“较上季度”，不用孤立的“+20%”。跨年长图可用“2025年第一季度”，同年轴标签可简化为“一季度”，年份必须在图题中明确。

期间未结束时：例如“截至9月28日的已记录销售额”，不能简称“9月销售额”并与完整8月比较。同比使用可比的截至日或匹配营业日；不能因为数字好看自由切换基准。中国长假、农历节日、季度天数、退货观察期影响解释时需说明。

报告制作日、业务截止日、数据最后同步日分别记录。尚未同步的账户或来源不是“没有发生”。

## 分子、分母和加权

总体转化率＝总转化数÷总机会数，不能直接平均各渠道转化率。例：10／100与900／10,000的总体为910／10,100≈9.01%，不是9.50%。

正文优先“32.5%（65／200份有效反馈）”。若图中每条都写分母太拥挤，可以在图题统一注明“有效反馈200份”，每条保留数量和比例。

加权调查同时给“加权比例”和“未加权样本量”；二者不必数值相乘相等。严禁把加权32.5%×样本数四舍五入伪造人数。不同问题有效样本不同，分别注明。

多选题、多主题编码可以超过100%，必须写清“同一反馈可包含多个主题”；不能画成合计100%的构成饼图。词频、提及次数不等于人数。

## 净增量份额与增长贡献

互斥渠道本期减基期，分项变化应加总到总体。净增量份额＝渠道变化÷总体变化。某渠道增长100、另一渠道下降60，总增长40，则份额可为250%与−150%。这是净额分解，不应塞进饼图，也不能截为100%。

总变化为0或接近0时，份额无定义或极不稳定；展示绝对变化并说明情况。需要稳定比较可另外列正向增量总额与负向变动，但不能把这个新分母继续称作总体净增量。

## 基期为0、负数和异常值

基期为0时只给“从0增至50”及绝对增量。利润从−100到50可写“由亏损100转为盈利50”，不直接用传统增长率。基期非常小时同时显示基数。异常值保留或排除都需明确规则，禁止只去掉不支持结论的数据。

## 舍入、合计与差额

先用原始精度计算，再统一展示。百分比总和因舍入变成99.9%或100.1%时注明舍入差异，不改动原始数据硬凑100%。合计项独立从原始数据计算；差额在数据精度和方法允许范围内核对。

金额与金额差额保留一致单位；同列小数位通常一致。避免“−0.0”，经舍入确为0时显示0.0，但必要时附原始微小变化。上下文需要识别微小差异时，直接提高显示精度。

## 缺失状态

0＝确实观察为零；未提供＝来源没有给出；未取得＝暂未访问；不适用＝指标不适用于该对象；待更新＝暂未成熟或未同步；估算＝模型或假设推算。不同状态不要统一显示为破折号而不解释。

折线缺失处断开，除非插值有明确方法与标识。未知队列留存单元格显示“未满观察期”，不涂成最差颜色。

## 财务与增长用语

不以GMV代替会计收入；不以收入增长推断利润增长。客单价是订单金额的均值，不等于商品售价。每千次送达收入以成功送达量为分母，不能与每千次发送收入混用。打开率受到测量方法影响时需核实，不凭单个打开率判断用户参与度。

“显著”仅在统计或业务阈值有定义时使用。正式金额范围重复必要单位，例如“5万—15万美元”，避免“5—15万”导致前端读者误解。
