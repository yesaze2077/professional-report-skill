## 仍需人工处理的边界

- 证据点的数字句、标题和图注属于自由文本。程序能检查引用 ID 及已声明算式，不能自动证明自由文本数字与指标语义完全一致；本示例已逐项人工复核，后续改动要再核对。
- 合成案例中的来源真实性、实际业务因果关系、预算与资源可行性均不由程序认证。
- HTML 幻灯在 390px 窄屏阅读时，宽表需要在表格容器内左右滑动。
